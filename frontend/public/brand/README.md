# Garden Party Cake Studio: logo files

These are based on the owner's original badge: a deep-green circle, cream hand-script "Garden Party", and small spaced "CAKE STUDIO" on a fine flourish line.

| File | Use |
|---|---|
| `logo-wordmark.svg` / `.png` | Horizontal script logo, green on light backgrounds (site header, staff sidebar) |
| `logo-wordmark-light.svg` | The same in cream, for dark backgrounds |
| `logo-badge.svg` / `.png` | Classic round badge, closest to the original |
| `logo-badge-botanical.svg` / `.png` | Badge with a leaf-and-blossom sprig (site footer) |
| `logo-badge-allura.svg` | Alternative badge in the more formal Allura script |
| `favicon.svg` | "GP" monogram for the browser tab |
| `logo-options-preview.png` | All the options side by side |

- **Fonts:** the lettering is converted to shapes, so no font is needed to view these files. The fonts are Dancing Script, Allura and Jost, all under the SIL Open Font License, which allows logo use.
- **Colors:** deep green `#23402a`, cream `#f4ecd6`, blush `#e9b8b0`, leaf `#a9b98c`.
